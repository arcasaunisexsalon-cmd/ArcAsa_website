# ArcAsa Wiki Repository Rules

## Purpose

This repository contains the official knowledge base and documentation for ArcAsa Unisex Salon. All content should be accurate, professional, SEO-friendly, and consistent with the ArcAsa brand.

---

# Content Rules

* All information must be factually accurate.
* Do not publish unverified claims.
* Use clear, professional English.
* Write in third person unless creating marketing copy.
* Keep paragraphs concise and readable.
* Avoid duplicate information.
* Update outdated content promptly.

---

# Brand Guidelines

Always use the full brand name:

**ArcAsa Unisex Salon**

Do not abbreviate the brand unless the context requires it.

Maintain a premium, friendly, and trustworthy tone.

---

# Writing Style

* Use Markdown.
* Use descriptive headings (H1, H2, H3).
* Prefer bullet lists for services.
* Keep sentences concise.
* Use active voice.
* Avoid excessive promotional language.
* Use title case for headings.

---

# SEO Guidelines

Include naturally relevant keywords such as:

* Unisex Salon in Bhubaneswar
* Hair Salon
* Beauty Salon
* Bridal Makeup
* Nail Studio
* Hair Spa
* Hair Color
* Keratin Treatment
* Facial
* Makeup Artist
* Groom Makeup

Do not overuse keywords.

---

# Images

* Use descriptive filenames.
* Add meaningful alt text.
* Optimize image sizes.
* Avoid copyrighted images without permission.

---

# File Naming

Use lowercase with hyphens.

Examples:

* `bridal-makeup.md`
* `hair-services.md`
* `nail-extensions.md`

Avoid spaces.

---

# Commit Messages

Use conventional commits.

Examples:

* feat: add bridal makeup page
* fix: update salon address
* docs: improve service descriptions
* seo: optimize homepage keywords
* chore: reorganize wiki structure

---

# Pull Requests

Each pull request should include:

* Summary of changes
* Reason for changes
* Screenshots (if applicable)
* SEO impact (if applicable)

---

# AI Content Policy

AI-generated content must:

* Be reviewed by a human.
* Reflect actual ArcAsa services.
* Avoid fabricated awards, certifications, or customer reviews.
* Match the salon's current offerings.

---

# Prohibited Content

Do not include:

* False claims
* Copyrighted material without permission
* Customer personal information
* Competitor defamation
* Offensive or discriminatory language

---

# Repository Structure

/docs
/services
/gallery
/blog
/assets
/images
/branding

---

# Review Checklist

Before merging, verify that:

* Grammar and spelling are correct.
* Facts are accurate.
* Headings are properly structured.
* Internal links work.
* Images include alt text.
* Content aligns with the ArcAsa brand.
* SEO metadata is included where appropriate.
