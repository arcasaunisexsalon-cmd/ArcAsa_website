## ✨ About

This repository contains the complete source code for the **official ArcAsa Unisex Salon website**.

The website showcases our salon's services, portfolio, pricing, offers, contact information, online booking, and brand identity while delivering a fast, responsive, and SEO-optimized experience.

## 💇 About ArcAsa

**ArcAsa Unisex Salon** is a premium beauty destination located in **Chandrasekharpur, Bhubaneswar, Odisha**, offering professional salon services for women, men, and children.

Our mission is to provide modern beauty, hair, skincare, nail, and makeover services with exceptional customer care.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/arcasaunisexsalon-cmd/ArcAsa_website.git
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```
